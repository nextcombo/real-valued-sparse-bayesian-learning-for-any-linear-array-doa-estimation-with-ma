# Real-valued Sparse Bayesian Learning for Any Linear Array DOA Estimation [with MATLAB Code]

Sparse Bayesian Learning (SBL) has become a popular approach for direction of arrival (DOA) estimation, but its computational complexity for Bayesian inference is quite high due to the need to compute the inverse of large complex matrices at each iteration. It is well-known that converting the complex valued problem into a real valued one can reduce the computational load. However, common real valued transformations are only applicable to Uniform Linear Arrays (ULAs). In this paper, we propose a new real valued transformation for any linear array by leveraging the virtual steering of the linear array. We then introduce an alternating optimization algorithm based on Variational Bayesian Inference (VBI) method to obtain the steady-state solution for the real valued sparse representation problem iteratively. By utilizing additional real valued structures, the VBI scheme achieves better performance in terms of estimation accuracy and computational complexity. Furthermore, we incorporate Generalized Approximate Message Passing (GAMP) into the VBI based method to further reduce complexity. Although the GAMP variant may result in performance loss, simulation results show significant improvements over existing methods.
Introduction
Over the past thirty years, the DOA estimation problem has attracted great attention in array signal processing [1] and now there is renewed interest in next generation wireless communication, especially for large scale multi-input multi-output channel estimation [2^-[4^]. Many subspace type high resolution algorithms (e.g., MUSIC, ESPRIT, and PUMA) have been proposed for DOA estimation. According to subspace principle, an M-element uniform linear array (ULA) can resolve up to (M−1) sources. Several non-uniform array geometries (e.g., minimum redundancy array, nested array, and coarray) have been studied in literature which can achieve much higher degrees of freedom than ULA and can identify more sources than the number of sensors [11^-[13^].

For example, the so-called SS-MUSIC method [9] can identify up to O(M2) sources with M elements in an array. However, for subspace-based methods, a large number of snapshots are required to accurately capture both the signal subspace and/or noise subspace, and if the Signal-to-Noise Ratio (SNR) is low, DOA estimation performance may be significantly degraded.
Recently, Sparse Representation (SR) [15], [16] has become a very popular DOA estimation technique due to its several advantages, such as improved robustness to noise and suitability for limited number of snapshots and/or unknown number of sources. Many SR-based DOA estimation methods have been proposed [17]–[22]. For example, in [17], a DOA estimation method named l1-SVD was developed, which relaxes the non-convex l0-norm sparse recovery problem into a convex l1-norm minimization problem. However, l1-SVD suffers from modeling errors between true DOA and grid points due to the direction mismatch. Such modeling errors exist in many SR-based DOA estimators, including Covariance Matrix Sparse Representation (CMSR) [21] and Sparse Iterative Covariance-Based Estimation (SPICE) [22]. On the other hand, there are several meshless methods. For example, Atom Norm Minimization (ANM) [23] can recover sparse signals without being restricted by the mesh. Additionally, it is suggested to use ICSPICE [24] that combines the Capon [25] and SPICE [22] methods to estimate angle deviations from the grid.
Sparse Bayesian Learning (SBL) is one of the most attractive methods for sparse recovery [26]–[28]. If a Gaussian Scale Mixture (GSM) model is used to represent the Laplace prior at the hierarchical level, then from the Bayesian perspective, it includes l1 norm minimization as a special case [29]. As theoretically demonstrated in [26], [30]–[33], SBL-based methods can smooth out many bad local minima and have strong capabilities to handle highly correlated dictionary matrices by introducing data-dependent penalties. Therefore, SBL-based methods are expected to achieve better sparse recovery. Moreover, it is easy to incorporate off-line models into the SBL framework to deal with modeling errors caused by direction mismatch [34], [35]. [36] proposed an SBL-based nested array DOA estimation method that introduces a second-order approximate model to alleviate direction mismatch. To avoid noise variance estimation, only trimmed virtual steering is used. Due to the greatly reduced work array aperture, DOA estimation performance will be degraded. Applying a second-order approximation can mitigate the off-line gap, but if coarse grids are adopted, it still may lead to higher modeling errors. To overcome the above two drawbacks, our previous work [37] provided an improved SBL-based method to estimate DOA from the entire virtual steering and proposed a new grid refinement procedure to eliminate modeling errors caused by direction mismatch. Compared with the state-of-the-art estimators, [37] can provide higher DOA estimation accuracy, but it involves demanding computational complexity to evaluate the inverse matrix of a large complex matrix for each iteration. An additional grid optimization process will further increase the computational load. Therefore, it prompts us to seek an effective method to reduce complexity.
We note that by converting the complex valued problem to a real valued one, we can reduce the computational load as the cost of complex multiplication is four times that of real multiplication. Many studies have been conducted to reduce the computational complexity in array signal processing [18] [38] [39], but most of them are only applicable to ULA. On the other hand, obtaining another real valued transformation by separating the real and imaginary parts of the complex valued problem is quite simple [40]. However, this transformed real valued problem size becomes twice the original problem size, which does not alleviate the computational burden. In this paper, we propose a novel real valued transformation for arbitrary linear arrays, then design two effective real valued DOA estimation methods. Our contributions are summarized as follows:
New Real Valued Transformation
By exploiting the special property of virtual steering in linear arrays, we introduce a new real valued transformation for DOA estimation of arbitrary linear arrays, which can transform the original complex valued SR problem into a real valued and dimensionally reduced form. Therefore, using the new real valued transformation can save a lot of computation, and when the additional real valued structure inherently contained in the new transformation is used, it is expected to achieve higher DOA estimation accuracy.
General Framework Based on SBL for Real Valued DOA Estimation
We design a general framework based on SBL for real valued DOA estimation using any linear array. First, an alternating optimization algorithm based on variational Bayesian inference (VBI) method [41] is proposed to perform Bayesian inference. Different from traditional VBI methods, we convert the function optimization problem into a regular parameter optimization problem and prove that the iterative sequence generated by the alternating optimization algorithm converges to a stationary point [42]. Then, we incorporate the Generalized Approximate Message Passing (GAMP) [43] into the VBI method to obtain a fast variant for DOA estimation using any linear array. Simulation results show that our solution has significantly improved performance compared to existing methods.
Conclusion
We have derived two effective real-valued methods for DOA estimation using any linear array. Although several real-valued methods have been proposed in the literature, most of them are only applicable to ULA. By applying Lemmas 1 and 2, we were able to construct a new real-valued transformation for DOA estimation that can convert the original complex-valued SR problem (27) into a real-valued and size-reduced SR problem (27). Following the main idea adopted in [42], we provided an alternating optimization algorithm based on the VBI method to estimate DOA from the real-valued SR problem (27), and demonstrated that the VBI method can achieve a stable solution. To further reduce computational complexity, we also designed a fast GAMP version. Although it is difficult to prove the convergence of the GAMP algorithm, simulation results indicate that it runs very fast and can provide comparable RMSE performance to existing methods.
